# astroid <4 is deliberate: astroid 4 made ``manager`` a required argument to
# ``AstroidBuilder()``, which sphinx-autoapi <3.8 calls with no arguments.

# emits an *empty* API reference while still exiting 0 — a green build with no
# API docs. Pinning astroid keeps any resolvable AutoAPI 3.x working.
